# StructRL project page

This folder is a dependency-free static project page for the paper **StructRL: Structured Action-Space Exploration for Flow-Based VLAs**.

## Local preview

Open `index.html` in a browser, or serve this directory with any static HTTP server. The page includes the ICLR manuscript PDF, image assets, and two real-world videos.

## Publish on GitHub Pages

1. Create an empty public GitHub repository, for example `flyfaerss/structrl`.
2. Upload the **contents** of this folder to the repository root (not the folder itself).
3. On GitHub, go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. The project page will be available at `https://flyfaerss.github.io/structrl/` after GitHub finishes deployment.

For the account-wide address `https://flyfaerss.github.io/`, create the repository named exactly `flyfaerss.github.io` instead and upload the same folder contents there.
